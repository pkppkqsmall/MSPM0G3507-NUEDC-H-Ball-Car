# H 题地图底盘运行说明

## 当前目标

当前程序的 `M1` 对应 H 题第 2 问，先验证题目地图的底盘部分：

1. 小车放在 A 点，车头朝 B 点。
2. 短按 B21，顺时针连续循迹。
3. 离开起点后完成一圈。
4. 再次检测到 A 点横线时自动停车并显示用时。

滚球位置 PID 和步进目标位置跟踪已接入。机构没有零位开关，因此比赛时
应把摆杆放到固定、近似水平的姿态再上电；程序会把上电姿态自动认作软件
零点，并用独立 `level trim` 抵消固定安装坡度。M2~M5 短按 B21 后会
自动启用各自的滚球闭环，不需要串口发送 `BALL,ZERO` 或 `BALL,ON`。

题目模式固定映射如下：

| OLED 模式 | 对应题目 | 当前状态 |
| --- | --- | --- |
| `M1` | 第 2 问 | 已接入当前一圈循迹和 A 点停车流程 |
| `M2` | 第 3 问 | 已接入静止滚球 `0 -> +5 cm -> -5 cm` 自动时序 |
| `M3` | 第 4 问 | 已接入 A→B 巡线、滚球中心保持、计时和停车 |
| `M4` | 第 5 问 | 已接入整圈循迹、中心保持、30 s/最大误差统计 |
| `M5` | 第 6 问 | 已接入整圈循迹和指定位置保持，目标赛前设置 |

上电默认选择 `M1`。停车时按 `SW1` 选择上一个模式，按 `SW2` 选择
下一个模式，模式编号在 `M1~M5` 之间循环。运行中忽略 SW1/SW2，防止
误触切换控制流程。

## 当前底盘

当前机械平台已换为 WHEELTEC R3X 加大版三轮差速底盘。厂家 STEP
模型和三轮差速尺寸图给出的主要尺寸如下：

| 项目 | 模型尺寸 |
| --- | ---: |
| 底板外形 | `320 x 240 x 5 mm` |
| 左右驱动轮中心距 | `214.2 mm` |
| 驱动轮轴至万向轮轴距 | `204.7 mm` |

电机、轮胎、编码器和驱动板没有变化，因此仍使用 `65 mm` 轮径、
`728 count/圈`、原速度 PI 和 PWM 参数。当前巡线不再使用编码器路段
规划；灰度位置先生成目标 yaw 角速度，BNO085 角速度反馈再修正左右轮
差速。BNO085 数据不可用时会自动回退到原灰度 P 控制。

## 操作

1. 上电后确认 OLED 显示 `M1 Q2 READY B21`。
2. 抬起车轮，分别转动车轮，确认 OLED 的左右 RPM 不会方向异常。
3. 停机时用黑线分别遮住最左和最右探头，OLED 或 `LINE?` 应依次显示
   `G=00000001 E=-16.00`、`G=10000000 E=+16.00`。
4. 将车放在 A 点并朝 B 点，短按 B21 起跑。
5. 运行中按下 B21 会立即手动停机。
6. 停止时长按 B21 至少 1.5 秒可进入灰度校准，按 OLED 提示依次确认黑色和白色。
7. 停止时使用 SW1/SW2 切换题目模式；M1~M5 均可启动。M2~M5 比赛
   启动前需要先把摆杆放到固定、近似水平的姿态再上电，并保证摄像头
   持续发送有效位置。M5 将钢球放到评委指定位置后短按 B21，程序会在
   同一次按键中采集当前位置作为目标并立即起跑，不需要蓝牙设定。
8. 蓝牙串口使用 `115200,8,N,1`；当前自动 VOFA 测速帧已关闭，使用
   `CAR?`、`BALL?`、`CAM?` 按需查询状态。

## 状态流程

```text
M1 Q2 READY
  -> B21 短按
RUNNING
  -> 120 count 后确认离开 A 点横线
  -> M1 在 21000 count 启用航向外环，所有模式在 21300 count 解锁终点
  -> 至少 3 路黑线连续确认 3 次
  -> M1/Q2 主动刹车 100 ms
DONE

RUNNING
  -> M4/M5 全白时保持最后灰度方向并继续角速度环
  -> 其他模式全白时保持丢线前左右轮目标
  -> 再次检测到黑线后恢复实时更新
```

M1/Q2 的编码器距离只用于终点解锁，真正停车仍来自 A 点横线。按 65 mm
车轮和 728 count/圈估算，理论一圈约 `21895 count`；程序在
`21300 count` 后才允许至少 3 路横线触发。Q5/Q6 不再读取横线停车，改为
平均编码器达到 `25590 count`（比实测停车点缩短约 0.5 m）且 BNO085 累计
实际转角达到 `360°` 后触发缓停；IMU 不可用时由编码器终点单独触发。M1 在
`21000 count` 开始用起跑 yaw 作为
目标航向，通过 BNO085 角速度内环消除出弯后的姿态和残余转动。
没有小球的 M1/Q2 在触发后使用 AT8236 低侧慢衰减刹车 `100 ms`；
M4/M5 捕获终点左右轮 PWM 并用 `500 ms` S 曲线降到 0，同时叠加正向
钟形制动前馈，停车后步进位置跟踪继续以停车包络保持本轮目标。

## M2 第 3 问静止滚球

第三问不启动底盘电机。比赛开始前先将摆杆放到固定、近似水平的姿态再给
整机上电，把钢球放在中心点 O，摄像头坐标应位于 `0±15 mm`，然后切到
M2 并短按 B21。当前调试流程先把摆杆机械调平并以该姿态归零，默认
`level trim=0`：

```text
检查上电软件零点和新鲜摄像头数据
-> 正程固定 -4.5°，不再在位置闭环和静摩擦辅助之间反复切换
-> 用平滑球速预测 0.85 s 后的位置，预测峰值达到 +39 mm 时下发固定 +3.0° 返程坡度（为 +40 mm 目标预留 1 mm 量化裕量）
-> 返程达到至少 -100 mm/s 左移速度且 RawX 回到 +20 mm 时，下发柔和制动角
-> 按 |V|+40 mm/s、固定 70 mm 制动距离和 v^2=2as 计算反刹，限制 -1.5~-3.0°
-> 左移期间制动角只允许增强，不因单帧零速或假反向提前撤坡
-> RawX 到 -35 mm 且融合速度 |V|<=70 mm/s 时，短暂预置 +2.2° 上抬角
-> 上抬 100 ms 后进入位置-速度串级 PD，不再固定保持 +1.8°
-> 位置外环 Vref=clamp(-1.5*(RawX+50), -60, +60) mm/s
-> 速度内环 Angle=1.8+clamp(0.040*(V-Vref), -2.4, +2.4)°，捕获段不积分
-> 首次回弹仍由能量制动继续吸收，不再立即切换终点 PID
-> 即时速度与聚合速度同时连续低于 12 mm/s 达 75 ms，才允许进入终点捕获
-> 若双速度低速且 RawX>-30 mm，恢复固定 +3.0°；否则直接交给终点自适应
-> 已在合格区且双速度均低时直接冻结制动角
-> 终点自适应用 35 mm/s、1.2/s 速度包络向 -50 mm 收敛
-> 误差 6~15 mm 间由速度包络渐变回位置反馈，并用单帧速度提前反刹
-> 终点自适应从当前制动角的 ±2° 范围内平滑接管并学习当地坡度
-> 提前反刹要求单帧位移和融合速度方向一致；越过目标继续远离时也可立即反刹
-> 在 -4~-6 cm 连续低动 100 ms 后冻结当时的实际摆杆角，不再额外推一次
-> 冻结角验稳 250 ms，窗口摆幅不超过 2 mm 且末端球速不超过 4 mm/s 时完成
-> 未在合格区才启用 -50 mm 自适应；完成后离开合格区才恢复自适应
```

总时间不超过 `5 s` 时 OLED 显示 `M2 PASS`，否则显示 `M2 LATE`，
完成后步进继续保持验稳时锁定的局部平衡角。该角度不是软件 `0°`，而是
终点自适应过程根据当前管道坡度和摩擦学到的局部平衡角。`+40 mm`
已满足 `+5±1 cm`。由于步进在 `-4.5°` 和正角之间换向约需 `150 ms`，
程序必须在球真正到达端点前下发命令。固定 `+5 mm` 切换实测峰值仅
`+22 mm`，固定 `+20 mm` 在较高起滚速度下又冲到 `+111 mm`，因此改为
`Peak=X+0.85*clamp(V,0,80)`；预测值达到 `+39 mm` 时下发 `+3.0°`
返程坡度。返程达到至少 `-100 mm/s` 左移速度且 RawX
回到 `+20 mm` 后，下发 `-1.5~-3.0°` 柔和制动角。低于该速度时继续
建立左移动量，避免在正区提前刹停并反复补送。
只有负端制动角随实测速度变化，避免视觉峰值量化、
滞后球速和旧的重送分支造成重复往返。即时速度以相邻帧为主、通用球速
为辅；固定 `70 mm` 制动距离不会在接近 `-50 mm` 时出现除零或角度发散。
`+1.8°` 只作为负端初始坡度估计，管道不水平、局部弯曲和静摩擦差异仍由
终点积分在线学习，不要求整根管道共用一个水平角。
终点局部平衡偏置只在接近 `-50 mm` 时渐入，远端优先服从速度包络，
避免偏置方向压过回中方向。
终点交接同时检查相邻帧即时速度和滞后三帧左右的聚合速度。单帧位置量化
可能在球仍有明显动量时短暂给出反向速度。为补偿步进约 `100 ms` 的换向
时间，RawX 到 `-35 mm` 且融合速度降到 `70 mm/s` 以内时即预置
`+2.2°`。保持 `100 ms` 后改用位置-速度串级 PD：位置误差按 `1.5/s`
生成最高 `60 mm/s` 的预期速度，实际速度相对预期速度每偏差 `25 mm/s`
修正 `1°`，修正上限 `±2.4°`，并叠加 `+1.8°` 局部平衡偏置。捕获段不使用
积分，避免积累后再次把球推出终点。两种速度都连续低于 `12 mm/s` 达
`75 ms` 后才允许交接；若此时 `RawX>-30 mm`，程序恢复固定 `+3.0°`
继续送球，`-30 mm` 以后则直接由终点自适应克服静摩擦，避免停在
`-35 mm` 后因达不到重新制动所需速度而卡死。终点误差大于
`15 mm` 时按最高 `35 mm/s`、
`1.2/s` 的位置-速度包络回收，误差小于 `6 mm` 时恢复原位置反馈，
中间线性渐变；自适应角再做一阶低通且每帧最多变化 `0.45°`，
避免摄像头速度换向时让步进目标来回跳动，也不使用持续抖振。
正程固定角只用于 M2/Q3，不修改第四问或用户保存的 PID。它消除了起滚后
闭环主动减小坡度而再次卡住的问题；RawX 到 `+10 mm` 且已确认向右起滚后
提前换向，不等待
小球在正端静止。实际峰值仍应通过 `BALLLOG` 确认落在
`+40~+60 mm` 内。
若误差仍大于 `8 mm`、融合速度不超过 `6 mm/s` 且单帧位移不超过
`0.5 mm`，说明球可能卡在静摩擦区，此时按目标方向短暂请求完整
`±4.5°` 破静摩擦角；检测到重新运动后立即撤销，并恢复普通
`±3.5°` 限位，避免正常滑行时额外加速。
终点环在单帧位移达到 `0.5 mm` 时混入当前 40 FPS 速度，弥补三帧聚合速度在反向点
的滞后；低速时仍使用聚合速度，兼容坐标量化。制动、最后定位和连续停稳时间
都计入比赛总时间。M2/Q3 启动时会自动开启 `100 ms` 的 `BALLLOG`。
到达判定直接使用摄像头新帧，主循环不会重复计算同一帧。运行中按 B21 或发送 `STOP` 可立即
终止；切换题目模式也会关闭滚球保持。

比赛现场不需要串口，操作顺序如下：

```text
摆杆放到固定、近似水平姿态 -> 整机上电 -> 钢球放在 O 点
-> SW2 从 M1 切到 M2 -> B21 短按启动
```

串口调试时可使用：

```text
STOP
BALL,OFF
手动将摆杆放到固定、近似水平姿态
BALL,ZERO
BALL,PID,0.0075,0.015,0.03
BALL,DELAY,0
BALL,TRIM,0
BALL,LOG,ON
BALL?
```

确认 `Zero=1 Ready=1`、`X` 接近 `0 mm` 后，用 SW2 将 `M1` 切换到
`M2`，再短按 B21。M2 会自动启用滚球控制，不需要另外发送 `BALL,ON`。
`MAP?` 可查看 `Stage=PUSH+/RETURN/V-CATCH/ADAPT-END/VERIFY/HOLD-END`、计时、
聚合/即时球速、当前手动倾角、自适应偏置和计算出的制动角。
首轮测试保留 `BALL,LOG,ON`，结束后发送 `BALL,LOG,OFF`；正式比赛前
应关闭诊断 CSV，避免无关串口流量。

## M3 第 4 问 A→B

第 4 问要求从 A 点出发并通过 B 点，AB 长 `1.5 m`、用时不超过 `8 s`。
65 mm 车轮以 7 秒完成 1.5 m 的理论转速约为 `63 RPM`。程序先让滚球
闭环稳定 `200 ms`，再从最低可用的 `30 RPM` 通过 `1400 ms` 三次平滑
曲线升至 `88 RPM`。接近 B 点时从 `4950 count` 开始减速，到
`5700 count` 降至 `35 RPM`。终点条件满足后不再立即断 PWM，而是捕获
左右轮当前占空比，在 `900 ms` 内用 S 曲线衰减到 0，再正式完成停车。
正常停车在越过 B 点约 `9.8 cm` 后触发，考核需要的 A-B 通过时间不受
后续缓停完成时间影响。
实测向车后滑对应摄像头 `X<0`，因此起步前 `180 ms` 先渐入 `-0.85°`
预置角，并在起步后的 `600 ms` 内渐出；起步 S 曲线再叠加峰值
`-1.30°` 加速度前馈，终点距离减速
前半段升到 `+0.70°`，随后保持到最终停车接管。
起步前馈只有在小球已经回到 `X>=-2 mm` 后才允许按回中速度撤销，避免
速度估计尖峰在小球仍位于负侧时提前取消补偿。
最后 `900 ms` PWM 缓降从 `+0.70°` 连续起步，叠加峰值 `+0.45°` 的钟形
制动项。PWM 归零时，只有球仍位于正侧且继续向正侧滚动，才保留最多
`300 ms` 的 `+0.80°` 接球角；球已经越过中心或已经反向时不再重新施加，
避免停车后二次推向负侧。行驶阶段小球落到 `X<-8 mm` 时也会直接禁用
停车正角。前馈只叠加到摆杆角度，不修改目标位置和 PID 积分。
为防止行驶扰动把球推到 `±10 mm` 之外，M3 还单独启用中心保护：偏差
超过 `2 mm` 后按 `0.055°/mm` 计算，最多叠加 `0.75°`。保护角不再只看位置；球静止或继续
远离中心时完整介入，球已向中心运动时按实际速度逐渐退出，达到规划
回中速度后完全交给速度反馈制动，避免两个控制项互相抵消。
第四问另外使用中心 `0 mm` 作为每次回调终点的位置-速度包络：行驶时
最高回拉速度限制为 `15 mm/s`，目标速度按 `0.50 × 剩余距离` 递减。
速度阻尼使用最短 `35 ms` 的独立短窗估速，检测到换向时立即采用新方向，
并按 `0.018°/(mm/s)`、最大 `0.90°` 叠加。
停车后切换到 `15 mm/s / 0.5/s` 的柔和保持包络；正常 `±10 mm` 内不叠加
额外中心保护，只有球超界且速度不高于 `6 mm/s` 时才按 `0.10°/mm`、
最大 `1.0°` 温和回中，球重新滚动后立即退出。

M3 短按 B21 后会先检查步进软件零点、摄像头新鲜有效帧以及钢球是否在
中心 `±10 mm` 内。通过后自动清空旧积分，保留赛前设置的 `BALL,PID`、
`BALL,TRIM` 和方向参数，将目标设为 `0 mm` 并开启步进位置跟踪。运行中
会自动打开 `100 ms` 周期的 `BALLLOG` 蓝牙诊断，并记录摄像头原始位置的
全程最大绝对误差。摄像头超过 `300 ms` 未更新或
滚球闭环被关闭时，摆杆回软件水平，但底盘继续循迹；视觉恢复后滚球控制
自动重新接管，避免比赛中途停车直接失分。

停车采用传感器与编码器组合判断：

```text
4500 count 后，右二探头 bit6 / 0x40 看到黑线 -> 锁存 B 点特征

(已锁存右二黑 && 距离 >= 5700 count)
||
距离 >= 5950 count
-> 触发 900 ms PWM 平滑停车
-> 停稳后显示 M3 B PASS 和总用时
```

`5700 count` 约为 `1.60 m`，`5950 count` 约为 `1.67 m`。右二信号在
4500 count 前不参与判断，避免直线摆动导致提前停车。正常通过 B 后只停
底盘，滚球闭环继续保持中心，避免停车冲击后失控。OLED 最后一行显示当前
`X`，`MAP?` 可查看 `En/Ready/X/Max/Limit`；`Max<=10 mm` 才满足题目误差。
`MAP?` 的 `Phase` 显示 `HOLD/START/CRUISE/BRAKE/STOPPING`，`Plan` 是当前规划
速度，`FF` 是当前底盘加减速前馈角。
第一次实车运行前仍须确认方向、软件水平零点、`BALL,TRIM` 和相机坐标。

## M4/M5 第 5、6 问基础循迹

第 5、6 问均要求顺时针运行一圈并通过 A 点，总时间不超过 `30 s`。
两种模式共用一套带球循迹、一圈完成判断和移动中滚球控制：

- M4/Q5、M5/Q6 先静止 `200 ms` 建立摆杆预置角，再从 `30 RPM` 通过
  `1400 ms` S 曲线平滑升至 `85 RPM`。
- 启动前必须有软件零点和新鲜摄像头帧，并且钢球位于目标 `±10 mm`；
  条件不满足时拒绝起跑，不会只启动车轮。
- M4/Q5 每次起跑强制目标为中心 `0 mm`。M5/Q6 在短按 B21 时读取
  最新摄像头位置，将该位置锁定为本轮目标并立即起跑。
- 两种模式自动启用滚球 PID，使用第四问已验证的 `20 mm/s、0.75/s`
  位置-速度包络和速度耦合位置保护。
- 起步静止段用 `180 ms` 建立 `-1.05°` 预置角，起步后 `600 ms`
  平滑撤除，并叠加峰值 `-1.55°` 的钟形纵向加速度前馈；弯道只由
  位置/速度反馈处理，不把差速转向误当成纵向加速。起步阶段允许合成
  前馈达到 `2.2°`，巡航和停车仍限制为 `1.5°`。
- M4/M5 的中心误差缩放为 `0.25`，不再额外低通误差；外侧误差保持原强度。
- 转向误差按“当前基础速度 / `80 RPM`”同比缩放；稳态 `85 RPM`
  时系数约为 `1.063`，使提速前后的灰度转向强度保持接近。
- M3/M4/M5 内轮最低保持 `25 RPM`，外轮按转向强度增加、最高 `95 RPM`；
  单轮目标每 `10 ms` 最多增加 `3 RPM`，减速立即生效。
- 中心误差保持不变；误差绝对值超过 `2` 后，超出部分乘 `1.5`，
  让车辆在中间向外一档时提前建立转向，不等边缘探头才满纠偏。
- 两种模式出弯中心速度每 `10 ms` 恢复 `1 RPM`，外侧探头修正强度
  仍受目标角速度 `±60 deg/s` 安全限幅。
- 在 B/D 附近，最外两路可在宽编码器窗口内触发；右侧第三路在更靠近
  弯道的位置连续确认 2 次也可提前进入保持，避免等到最边缘才满纠偏。
- 半圆前段最低维持 `30 deg/s` 右转；累计 `170~175°` 时将最低请求
  平滑降到 `10 deg/s`。达到 `175°` 且中线连续确认 3 次后，先用
  `50 ms` 消除残余右转，再用 `200 ms` 渐入实时灰度控制；最长
  `400 ms` 自动结束过渡，避免出弯时从 0 突然恢复全量纠偏。
- 摄像头短时丢球使用最后位置和球速预测；持续超过 `300 ms` 时底盘
  继续循迹，摆杆回到标定水平，恢复有效帧后自动重新接管。
- 全程记录相对目标的最大原始位置误差；超过 `10 mm` 标记 `OVER`，
  超过 `30 s` 标记 `LATE`，两项都满足才显示 `PASS`。
- A 点完成后将当前左右轮 PWM 用 `500 ms` S 曲线降到 0，并叠加峰值
  `+0.80°` 的钟形停车前馈；随后滚球控制改用 `15 mm/s、0.5/s`
  停车包络继续保持目标。停车后若小球超出目标 `±10 mm` 且近似静止，
  自动启用温和位置保护，避免完成后继续漂移。
- Q5/Q6 默认关闭长 `BALLLOG`，改为每 `250 ms` 自动发送一条精简的
  `Q5BALL/Q6BALL`；字段依次为运行时间、位置、目标、误差、球速、摆杆角、
  最大误差、摄像头状态、帧龄、平均编码器距离和累计净顺时针转角。手动发送
  `BALL,LOG,ON` 后精简回传会暂停，
  只保留完整诊断 CSV，避免 `115200` 串口阻塞 10 ms 巡线任务。完成后
  精简回传继续保留 `5 s`，用于观察停车后的漂移和保持效果。

第五问现场步骤：切到 `M4`，把钢球放在 O 点，确认 OLED 最后一行
`X` 接近 `T:0`，短按 B21。第六问现场步骤：切到 `M5`，把钢球放到
评委指定位置，确认摄像头仍有有效数据后短按 B21；程序先锁定此刻 `X`
再立即起跑。蓝牙只用于赛前调试和查询，不是比赛启动条件。

题图中心线总长约 `6.142 m`。考虑弯道时中心速度低于外轮基础速度，
最终时间以实车为准。M4/M5 采用“离开 A 点、`21300 count` 后解锁、
确认第二个半圆已经退出、再次检测 A 点横线”的完成条件。

## 控制结构

地图运行时使用三层串级控制：

```text
当前灰度位图
-> 命中探头权重平均
-> 目标 yaw 角速度 = -5 x 灰度误差；M1/Q2 不限幅，其它模式限制在 ±60 deg/s
-> BNO085 相邻 yaw 求导并低通，得到实测 yaw 角速度
-> 角速度前馈 + P 反馈生成 turn_rpm；M1/Q2 不限幅，其它模式限制在 ±40 RPM
-> left = center - turn_rpm，right = center + turn_rpm
-> 左右轮速度 PI
-> PWM
```

灰度权重为 `{-16,-8,-4,-2,2,4,8,16}`。单独命中 4/5、3/6、
2/7、1/8 号时，M1/Q2 目标角速度依次为 `10、20、40、80 deg/s`；
其它模式的最外侧仍限制为 `60 deg/s`。M1/Q2 外轮始终保持 `120 RPM`，
只降低内轮形成差速；M3 出弯恢复时每 `10 ms` 增加 `2 RPM`，M4/M5
只增加 `1 RPM`，减小小球受到的纵向冲击。

编码器不直接产生弯道前馈；M4/M5 只用宽距离窗口限制弯道保持的触发
位置，真正触发仍要求右侧外探头检测到黑线。编码器还用于测速、无反馈
保护和一圈终点解锁，M3 中额外参与 B 点停车。M1 基础速度为 `120 RPM`，
M3 的稳态速度为 `88 RPM`，M4/M5 为 `85 RPM`。M3 的 4/5 号中心探头误差减半；
M4/M5 的中心误差缩放为四分之一，并按当前基础速度与 `80 RPM` 的比例放大
转向误差，不对灰度位图或误差数值做低通。
BNO085 使用 `50 Hz` GAME_ROTATION_VECTOR；连续 `150 ms` 没有有效
角速度时，程序自动使用原来的灰度 P 内轮减速逻辑。

| 通用滚球闭环角限位 | 动态 `1.5~4.0°` | 通用 PID/速度包络最终硬限位 `±4°`；直接角度转换仅为 Q3 静摩擦脱困保留 `±4.5°`。 |
| 球速估算时间窗 | 最少 `75 ms`、`1 mm` 静止带、断帧重置 `250 ms` | 聚合约三帧，避免坐标量化产生假速度。 |
| 摄像头失联保护 | 普通 `150 ms`、第三问 `250 ms`、第四问 `300 ms` | Q3 负向制动阶段短时失联继续保持已计算的负制动角，其它开环阶段回水平；第四问失联后只保留底盘前馈。 |
| 内轮低速处理 | `<=30 RPM` 时停驱动 | 避免进入低速开环后仍用较大 PWM 驱动内轮。 |
| 速度环 / 自动遥测 | `20 ms / 关闭` | 自动测速帧可通过源码开关恢复。 |
| `MAP_RUN_LAP_ARM_COUNTS` | `21300` | 允许 A 点横线触发停车的最小路程。 |
| `MAP_RUN_BALL_FIXED_STOP_COUNTS` | `25590` | Q5/Q6 写死停车的平均编码器距离，比上一实测点缩短约 0.5 m。 |
| `MAP_RUN_BALL_FIXED_STOP_MAX_COUNTS` | `28220` | IMU 异常时的编码器强制停车兜底，防止无限绕圈。 |
| `MAP_RUN_BALL_FIXED_STOP_TURN_DEG` | `360°` | Q5/Q6 正常同时要求的 BNO085 累计实际转动量；IMU 无新数据、超时或整段近似 0° 时，允许编码器终点单独停车。 |
| `MAP_RUN_FINISH_HEADING_ARM_COUNTS` | `21000` | M1 最后一段启用起跑航向外环。 |
| `MAP_RUN_FINISH_HEADING_KP_RATE_PER_DEG` | `2.0` | 每度航向误差叠加的目标角速度。 |
| `MAP_RUN_FINISH_HEADING_RATE_LIMIT_DEG_S` | `40 deg/s` | 航向外环角速度修正上限。 |
| `MAP_RUN_FINISH_LINE_ACTIVE_MIN` | `3` | 5 cm 横线至少同时命中的黑色探头数。 |
| `MAP_RUN_FINISH_LINE_CONFIRM` | `3` | 横线连续确认次数。 |

## 蓝牙测速

当前地图程序内置一组独立的速度环测试命令。`TARGET` 会选择速度测试
模式，随后发送 `START` 只运行速度环；`MAP` 会选择地图模式，随后发送
`START` 会启动灰度、yaw 角速度和速度 PI 串级。B21 短按也可以直接启动地图。
接线保持原工程不变：

| 蓝牙模块 | MSPM0G3507 |
| --- | --- |
| RX | PA10 / UART0 TX |
| TX | PA11 / UART0 RX |
| GND | 公共 GND |

程序保留 VOFA+ FireWater 帧格式，但当前
`MAP_RUN_AUTO_SPEED_TELEMETRY_ENABLED=0U`，不会自动发送：

```text
speed:target_left,target_right,actual_left,actual_right
```

例如 `speed:50.0,50.0,48.7,51.2` 表示左右目标都是 50 RPM，左轮实测 48.7 RPM、右轮实测 51.2 RPM。

摄像头 BLE 链路仍接收并解析以 CR、LF 或 CRLF 结束的 ASCII 消息。
当前 `MAP_RUN_AUTO_CAMERA_FORWARD_ENABLED=0U`，调试蓝牙不会自动同步输出：

```text
[CAM RX] 摄像头原始消息
```

发送 `CAM?` 可查询累计字节数、完整消息数、溢出次数和最近一条消息。
需要恢复自动输出时，将对应源码开关改为 `1U`。

### 滚球摄像头 PID

MaixCAM 每次识别到新图像后发送一帧，不要按主循环速度重复发送旧结果：

```text
BALL,frame_id,timestamp_ms,x_mm,valid\r\n
```

程序也兼容摄像头当前实际输出：

```text
[BALL] POS:+11.5cm\r\n
```

简化格式会自动换算为 `+115 mm`，并使用 MSPM0 收到完整行的时刻作为
采样时间。它可以直接闭环测试，但标准格式使用摄像头采集时间戳，速度估计
更准确。

字段约定如下：

| 字段 | 含义 |
| --- | --- |
| `frame_id` | 每张新图递增的无符号帧号。 |
| `timestamp_ms` | 摄像头采集该帧时的毫秒时间戳，用于计算真实 `dt`。 |
| `x_mm` | 小球相对横梁中心的位置，左负右正。 |
| `valid` | 找到可信小球为 `1`，未找到为 `0`；无效帧的 `x_mm` 请发送 `0`。短时无效帧由 MSPM0 预测补偿。 |

程序持续接收位置帧，但累计到稳定测速时间窗后才更新一次速度：

```text
位置低通 -> 累计至少 75 ms 的位置差 / vdt -> 1 mm 静止带 -> 速度低通
-> predicted_x = x + speed * delay，预测位移限制 ±20 mm
-> 位置距离生成朝向目标的速度包络
-> 6 mm 内使用原 PID，6~15 mm 平滑混合，15 mm 外使用速度包络
-> I 仅在目标 20 mm 内、低速有效帧按真实 dt 累加
-> 限制到 ±3.0°
-> 齿轮齿条运动学表分段插值
-> 步进目标脉冲
```

速度包络的目标速度同时受 `80 mm/s`、`1×剩余距离` 和
`sqrt(2×120×剩余距离)` 三项限制，使远端先加速、接近目标后提前
减速。I 输出限制为 `±1.5°`，误差超过 `20 mm` 或速度超过
`80 mm/s` 时清零；停机、失联、改目标或改参数时也清零。短帧继续
更新位置但保持上一速度，累计至少 `75 ms` 后才更新速度；测速位置变化
不超过 `1 mm` 时按静止处理，时间窗超过 `250 ms` 时清零旧速度并重建
基准。标准协议偶发 `valid=0`，或超过 `40 ms` 没有收到新位置帧时，程序
在最多 `100 ms` 内从最后有效滤波位置按球速衰减外推，外推位移限制为
`±12 mm`；有效帧恢复后由原位置低通
平滑接回，不使用无效帧中的 `x=0`。普通模式连续 `150 ms`、第三问连续
`250 ms` 没有有效帧时，
目标自动回到水平零点。当前 STEP 频率为 `8000 Hz`，从零位到
`±3°` 端点约需 `0.13 s`，两端完整反向约需 `0.26 s`。STEP 高电平
保持约 `10 us`，对应 16 细分电机转速约 `75 RPM`。

首次测试顺序：

1. 不放小球，人工把摆杆调到水平后发送 `BALL,ZERO`。
2. 让摄像头持续发送数据，先只用 `BALL?` 检查 `X/V/Angle/Pulse`。
3. 把物体从左移到右，确认 `X` 从负变正；若相反，先修正摄像头坐标。
4. 确认正脉冲确实抬高摆杆右端；若相反，在闭环关闭时发送
   `BALL,SIGN,-1`。
5. 抬空机构并准备随时发送 `BALL,OFF`，再发送 `BALL,ON`。
6. 方向和限位均正确后才放小球，并从较小 PD 参数开始调整。

## 现场判断

- 小车左右方向反了：立即按 B21 停机，先检查电机方向和编码器正方向，不要调巡线参数。
- 黑线偏右时，OLED 应接近 `G:10000000` 且 `E:` 为正；如果车辆仍向左修正，应检查电机左右方向，而不是再次反转灰度权重。
- 首次测试先手动向左转动车身并发送 `MAP?`，确认 `YawRate A` 为正；
  同时确认 `F=1`；若为负，禁止落地高速测试，应先修正 BNO085 yaw 方向。
- 直线左右摇晃：用 `MAP?` 比较 `YawRate T/A`；先调灰度到角速度增益，
  再调角速度 P，不要先修改轮速 PI。
- 弯道冲出：先确认 `C=1` 且目标/实测角速度同号，再增大角速度前馈或
  降低基础速度；运行时 `C=0` 表示正在使用灰度 P 回退，`F=0` 表示
  BNO085 角速度样本无效或已超时。
- 运行中全白：M4/M5 保持最后灰度方向并继续角速度环，其他模式保持
  丢线前轮速；所有模式都不会自动停车。
- 到 A 点不停车：观察 OLED 的黑线探头数 `A`；当前阈值为至少 `3` 路，
  若实测启停线稳定只能点亮 2 路，再改为 2。
- 提前误停车：提高横线阈值或连续确认次数，不要先依赖写死时间。

M1 起跑时给 `120 RPM`，转弯时外轮固定 `120 RPM`、只降低内轮；
M3 以 `30→88 RPM` S 曲线起步，出弯中心速度恢复为 `2 RPM/10 ms`；M4/M5 从
静止预置 `200 ms` 后由 `30 RPM` 通过 `1400 ms` S 曲线升到 `85 RPM`，
单轮目标每 `10 ms` 最多增加 `3 RPM`，
中心速度恢复为 `1 RPM/10 ms`，减速立即生效。
M4/M5 全白时继续运行最后灰度方向对应的角速度环，其他模式严格保持
丢线前左右轮目标；重新检测到黑线后恢复实时误差。起跑时若八路全白
仍会拒绝启动。

### 滚球诊断日志

发送 `BALL,LOG,ON` 后，串口先输出字段标题，随后每 100 ms 输出：

```text
BALLLOG,ms,frame,age,dt,vdt,en,stale,drop,raw,x,pred,set,v,e,ce,vref,blend,p,d,i,trim,ff,kick,kickms,kicka,profile,angle,limit,cmd,tgt,pos,lag,q3angle,q3bias,q3cap,q3lock,q3dx,q3vfb,q3vref,q3blend,q3push
```

- `age/dt/vdt`：有效帧年龄、单帧间隔和实际速度估算时间窗；短帧
  只更新位置，累计至少约 75 ms 后才更新速度。
- `drop`：`1` 表示当前位置来自短时丢球预测，`0` 表示来自有效视觉帧；
  `BALL?` 末尾的 `Drop=预测/恢复/超时` 用于统计预测是否成功接回。
- `raw/x/pred`：原始、滤波和延迟预测位置，单位 mm。
- `v/vref`：实际估算速度和位置-速度耦合规划的回中速度，单位 mm/s。
- `e/ce`：实际位置误差和加入延迟预测后的控制误差。
- `blend`：`0` 为中心附近 PID，`1` 为远端速度包络，中间为线性混合。
- `p/d/i/trim/kick/profile/angle/limit`：PID、固定水平补偿、静摩擦补偿、速度包络、最终摆杆角度及动态角度上限，单位度。
- `kickms/kicka`：连续低速时间和静摩擦补偿激活标志；激活后
  `kick` 从 `0.5~1.0°` 按 `1.8°/s` 增加，正、负方向最高均为 `2.4°`。
- `cmd/tgt/pos/lag`：控制器脉冲命令、步进目标、实际位置及跟随误差。
- `q3angle/q3bias/q3cap/q3lock/q3dx/q3vfb`：第三问当前手动角、已学习偏置、负端预捕获标志、终点冻结标志、最新一帧滤波位置变化和停稳判定使用的融合速度；`q3cap=1` 表示已经提前预置正向局部平衡角，最后两项单位为 mm 和 mm/s。
- `q3vref/q3blend/q3push`：第三问终点专用目标速度、包络混合比例和低速静摩擦位置推力；`q3blend=1` 为完全按速度收敛，`0` 为完全使用原位置反馈，`q3push` 单位为度且只应在允许区外卡住时非零。

调试结束立即发送 `BALL,LOG,OFF`。需要分析时，从开启日志前一行开始，
保留完整的回中过程和最后一条 `BALL?`，不要只截取球到达中点后的几行。
