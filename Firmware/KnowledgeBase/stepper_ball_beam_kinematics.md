## 齿轮齿条换算

小齿轮模数 `m=1.5`、齿数 `z=18`，理论节圆直径为：

```text
d = m * z = 27 mm
```

电机每转一圈带动齿条的理论行程：

```text
rack_travel_per_rev = pi * d
                    = pi * 1.5 * 18
                    = 84.823 mm/rev
```

当前电机为 `1.8°` 两相步进电机，驱动器和代码均按 16 细分：

```text
pulses_per_rev = 200 * 16 = 3200 pulse/rev
rack_travel_per_pulse = 84.823 / 3200
                      = 0.026507 mm/pulse
```

理论上每个 STEP 脉冲约让齿条移动 `0.0265 mm`。该结果以齿轮齿条无打滑、
驱动器细分确实为 16、STEP 输入一脉冲计一步为前提。

## 横梁角度换算

以实机水平姿态为 `0° / 0 pulse`。设：

```text
L = 263.309 mm
beta = -2.777100°
alpha = 横梁目标角，右端抬高为正
```

右端铰点相对水平零点的理论竖直位移为：

```text
delta_z = L * (sin(beta + alpha) - sin(beta))
pulse = delta_z / 0.026507
```

水平附近的近似比例为：

```text
1° 横梁角 ≈ 4.591 mm 齿条位移
1° 横梁角 ≈ 173.17 pulse
```

`±2°` 范围内非线性很小，但软件仍使用分段表格插值，便于以后用实测值
替换理论值。

### 实机方向约定

当前安装方向已确认：

```text
正方向：电机顺时针 -> 齿条上升 -> 横梁右端抬高
负方向：电机逆时针 -> 齿条下降 -> 横梁右端降低
```

滚球坐标仍采用横梁左侧为负、右侧为正。控制器默认
`output_sign=+1`，与当前机械方向一致。

较大时开放较大角度，接近目标时会自动收小。

## 几何约束与误差来源

1. STEP 中齿条沿 Z 方向导向，横梁右端铰点绕左轴走圆弧；`±2°` 时铰点
   还会产生不到 `0.5 mm` 的 X 向变化，真实结构必须靠铰接间隙或导向余量
   吸收，不能把机构视为完全理想的纯竖直约束。
2. STEP 没有保存装配运动副、齿隙、打印件弹性、螺钉间隙和实际碰撞关系。
3. 齿轮齿条回程间隙会造成同一脉冲位置在换向前后对应不同横梁角，后续可用
   BNO085 角度反馈或小幅单向预紧补偿。
4. ZDT 闭环只能降低电机本体失步风险；MSPM0 未读取驱动器位置反馈时，
   软件位置仍只是已发 STEP 脉冲的累计值。
5. 上电没有限位开关或绝对编码器时，程序不知道齿条绝对位置，必须人工调平
   后执行 `BALL,ZERO`。

## BNO085 反馈注意事项

横梁绕 Y 方向转轴运动。BNO085 使用 `roll`、`pitch` 还是 `yaw`，取决于
传感器实际安装方向，不能只按欧拉角名称猜测。

实机确认流程：

1. 固定 BNO085，手动抬高和降低横梁右端。
2. 观察 `roll/pitch/yaw` 中哪个量变化最大且连续。
3. 记录右端抬高时该角度的正负方向。
4. 横梁调平后记录零偏，再闭合角度反馈。

当前滚球控制首先使用脉冲位置开环验证机构，BNO085 尚未接入横梁角度闭环。

## 实机验证顺序

1. 保持 `BALL,OFF`，移除钢球并把横梁人工调平。
2. 确认 ZDT 上位机细分为 `16`，与
   `STEPPER_MICROSTEP_DIVISOR` 一致。
3. 发送 `BALL,ZERO`，把当前水平机械位置定义为软件 `0 pulse`。
4. 使用很小的目标角或手动点动，确认正脉冲是否抬高右端。
5. 若方向相反，在闭环关闭状态下使用 `BALL,SIGN,-1`，不要继续大幅运动。
6. 分别验证约 `±87 pulse` 是否接近 `±0.5°`，再逐步验证
   `±173 pulse` 和 `±346 pulse`。
7. 确认无卡齿、无顶死、无明显回程间隙后，才放入钢球并发送 `BALL,ON`。

## 当前软件接入状态

`App/MapRun/ball_beam_controller.c` 使用本页理论结果对
`-10°~+10°` 按 `1°` 节点分段线性插值，当前控制硬限位为 `±4.0°`，
因此最大目标约为 `-691~+693 pulse`。实际工作限位根据位置误差和球速
在 `1.5~4.0°` 间动态变化。

滚球位置环默认 `Kp=0.0075`、`Ki=0.015`、`Kd=0.030`。I 项只在误差
不超过 `20 mm`、速度不超过 `80 mm/s` 的有效时间帧累加，输出限幅
`±1.5°`；同时使用 `±2 mm`、`±10 mm/s` 中心静止区。当前 40 FPS
直连摄像头默认不做位置外推，手动启用时预测位移限制 `±20 mm`。误差 `6~15 mm`
之间从普通 PID 平滑切换到速度包络，普通控制远端期望回中速度最高
`60 mm/s`，第三问移动阶段临时提高到 `75 mm/s`；接近目标时按剩余
制动距离自动降低。摄像头数据
失联超过 `150 ms` 时，目标自动
回到软件水平零点。当前 STEP 频率为 `8000 Hz`，高电平约 `10 us`；
从零位到当前 `±4°` 硬限位约需 `0.17 s`，两端反向约需 `0.35 s`。
