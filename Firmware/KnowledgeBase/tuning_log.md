## 已知结论

| 主题 | 结论 |
| --- | --- |
| 巡线外环 | 灰度权重平均生成目标 yaw 角速度，不使用灰度 I/D 或路段前馈。 |
| 角速度内环 | 相邻 yaw 求导并低通，前馈加 P 反馈生成左右差速。 |
| 速度内环 | 高于 30 RPM 使用 `PI + 死区补偿`。 |
| 目标变化 | M4/M5 平滑起步，其余模式直接给基础速度；转向立即生效；出弯中心速度缓恢复；丢线保持原目标。 |
| 左右摆动 | 优先调整灰度到角速度增益或角速度 P，不先修改速度 PI。 |
| 圆弧跟随 | 先核对目标/实测角速度符号，再调整角速度前馈或基础速度。 |
| 丢线 | 保留最后灰度 P 方向、基础速度和左右轮目标，不自动停机。 |
| 编码器 | A 相双边沿、B 相判向，车轮实测约 728 count/圈。 |
| 一圈停车 | 编码器负责终点解锁，A 点横线负责最终停车确认。 |
