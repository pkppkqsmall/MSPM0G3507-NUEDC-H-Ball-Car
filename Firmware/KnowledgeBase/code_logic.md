# 当前工程代码逻辑

## 入口

当前实际编译入口是 `timx_timer_mode_pwm_edge_sleep.c`：

```c
int main(void)
{
    SYSCFG_DL_init();
    MapRun_Init();

    while (1) {
        MapRun_RunStep();
    }
}
```

`SYSCFG_DL_init()` 初始化 SysConfig 配置的时钟、GPIO、UART、I2C、PWM
和定时器；`MapRun_Init()` 初始化应用层和驱动运行状态；主循环不断执行
`MapRun_RunStep()`，所有任务均采用非阻塞轮询或短时操作。

## 当前模块边界

| 层级 | 目录 | 作用 |
| --- | --- | --- |
| 应用入口 | `App/MapRun/` | 按键、灰度校准、连续巡线、一圈停车、蓝牙测速和 OLED 调度 |
| 巡线串级 | `App/MapRun/map_yaw_rate_controller.*` | yaw 跨界处理、角速度估计和差速输出 |
| 半圆保持 | `App/MapRun/map_curve_hold.*` | M4/M5 右弯触发、跨界累计角和出弯对正 |
| 滚球控制 | `App/MapRun/ball_beam_controller.*` | 摄像头帧解析、真实 dt 速度估计、位置 PID 和齿轮齿条脉冲换算 |
| 电机 | `Drivers/motor/` | PWM、方向统一、编码器测速、低速开环和速度 PI |
| 灰度 | `Drivers/Sensor/` | CLK/DAT 串行读取和 KEY 校准控制 |
| 姿态 | `Drivers/BNO085/` | BNO085 数据就绪处理和 yaw/pitch/roll 更新 |
| 步进 | `Drivers/StepperMotor/` | STEP/DIR 固定运动和非阻塞连续目标位置跟踪 |
| 显示 | `Drivers/OLED_Hardware_I2C/` | OLED I2C 写入 |
| 平台 | `Drivers/MSPM0/` | SysTick、GPIO 中断和编码器边沿处理 |

`App/StateMachine`、`App/LineFollow`、`App/AngleTest` 等目录是未参与当前构建
的通用参考模块。当前地图运行不依赖这些目录。

## 初始化顺序

`MapRun_Init()` 的主要顺序如下：

```text
MotorPWM_InitDefaults()
-> SysTick_Init()
-> 开启全局中断
-> UART0 清空接收状态
-> OLED_Init()
-> StepperMotor_Init()
-> Sensor_Init()
-> BNO085_Init()
-> Interrupt_Init()
-> 设置 20 ms 测速周期
-> 设置左右轮 PI = 0.1 / 0.2
-> MotorSpeed_Reset()
-> 两轮速度环保持关闭
-> 初始化地图、按键、校准、传感器和显示状态
```

GPIO 组中断在 BNO085 初始化之后开启。同一个 GPIOB 组中断会处理 BNO085
数据就绪和左右编码器 A 相边沿；中断只做短操作，不在中断中执行 I2C 读取。

## 主循环顺序

`MapRun_RunStep()` 每轮按固定顺序调用：

```text
MapRun_UpdateBluetooth()
-> BNO085_UpdateIfDataReady()
-> 有新样本时更新 yaw 角速度估计
-> MapRun_UpdateButtons()
-> 处理 B21 立即停车、短按起跑、长按校准或 SW1/SW2 模式切换
-> MapRun_UpdateCalibration()
-> MapRun_UpdateControl()
-> MapRun_UpdateSpeedLoop()
-> MapRun_UpdateDisplay()
```

这些函数内部根据 `tick_ms` 判断是否到达执行周期，因此主循环本身不需要
阻塞延时。

## 地图状态

地图应用只有三个运行状态：

| 状态 | 说明 |
| --- | --- |
| `MAP_RUN_STATE_READY` | 待机，可以起跑、校准或进入速度测试 |
| `MAP_RUN_STATE_RUNNING` | 地图巡线或独立速度测试正在运行 |
| `MAP_RUN_STATE_FINISHED` | 已自动停车、手动停车或安全停机 |

另有两个控制模式：

| 模式 | 说明 |
| --- | --- |
| `MAP_CONTROL_LINE_FOLLOW` | B21 起跑，或蓝牙 `MAP` 后 `START` 的地图连续巡线 |
| `MAP_CONTROL_SPEED_TEST` | 蓝牙 `TARGET` 后 `START` 的纯速度环测试 |

速度测试模式不会调用灰度外环，避免 `TARGET` 被巡线目标覆盖。

地图控制之上还有一层题目模式：

| 题目模式 | 对应题目 | 当前行为 |
| --- | --- | --- |
| `M1` | 第 2 问 | 执行当前一圈循迹和 A 点停车 |
| `M2` | 第 3 问 | 底盘停机，滚球经过 `+40/-40 mm` 切换点并最终保持 `-50 mm` |
| `M3` | 第 4 问 | 30→88 RPM 平滑起步，从 A 巡线到 B 并保持小球在中心 |
| `M4` | 第 5 问 | 200 ms 预置后 30→85 RPM 整圈循迹，自动保持钢球中心并统计时间/最大误差 |
| `M5` | 第 6 问 | 与 M4 共用底盘和球控，B21 采集当前球位为本轮目标 |

## 三个按键

三个按键都使用非阻塞去抖，B21 另外区分短按和长按：

| 操作 | 结果 |
| --- | --- |
| 停止时短按 B21 | 当前题目模式已实现时启动；M5/Q6 先采集新鲜摄像头位置为目标 |
| 运行时按下 B21 | 一旦稳定按下立即关闭速度环和 PWM |
| 停止时长按 B21 至少 1.5 秒 | 进入灰度模块校准流程 |
| 停止时按 SW1 | 选择上一个题目模式，循环范围 M1~M5 |
| 停止时按 SW2 | 选择下一个题目模式，循环范围 M1~M5 |

运行中忽略 SW1/SW2，防止误触改变流程。M2 不检查灰度线，但会检查
步进软件零点、摄像头有效性以及小球是否位于中心 `±15 mm`；M3~M5
检查同样的零点和摄像头条件，并要求小球位于本题目标 `±10 mm`。
M1/M3/M4/M5 起跑时如果 8 路传感器全白，程序拒绝启动并发送：

```text
[MAP BLOCKED] No black line under sensor
```

## M1 第 2 问循迹

M1 使用 `120 RPM` 基础速度。灰度误差生成目标 yaw 角速度，BNO085
角速度前馈与 P 反馈生成 `turn_rpm`；M1 不限制这两个量。转弯时外轮
始终保持 `120 RPM`，只降低内轮形成差速，避免强纠偏结束后中心速度
缓慢恢复导致外轮突然变慢。内轮目标不高于 `30 RPM` 时直接停轮。

## M2 第 3 问滚球时序

M2 全程关闭左右直流电机，只调度滚球 PID 和步进位置跟踪：

```text
B21
-> 检查 Zero=1、摄像头数据新鲜、abs(X)<=15 mm
-> 固定 -4.5° 向正端驱动，避免位置闭环在局部静摩擦区反复停住
-> 用平滑球速预测 0.85 s 后位置，预测峰值达到 +39 mm 后固定 +3.0° 向左返程（+40 mm 目标预留 1 mm 量化裕量）
-> 目标是惯性把实际正端峰值送入 +40~+60 mm，返程不再按峰值二次切换
-> 返程达到至少 -100 mm/s 左移速度且 RawX<=+20 mm 后，下发柔和制动角
-> 用相邻有效帧和通用球速融合得到即时速度
-> 按 |V|+40 mm/s、固定 70 mm 制动距离和实心球模型计算 -1.5~-3.0° 反刹
-> RawX<=-35 mm 且融合速度 |V|<=70 mm/s 时，预置 +2.2° 并至少保持 100 ms
-> 100 ms 后用位置误差生成最高 ±60 mm/s 的预期速度
-> 用 0.040*(V-Vref) 修正 +1.8° 局部平衡角，修正限制 ±2.4°，不使用积分
-> 首次回弹仍由能量制动继续吸收，不再立即切换终点 PID
-> 即时速度和聚合速度同时连续低于 12 mm/s 达 75 ms 后才允许交接
-> 若双速度低速且 RawX>-30 mm，恢复固定 +3.0°；否则进入终点自适应
-> 合格区内双速度均低时直接冻结当前制动角，否则启用终点自适应
-> 以最高 35 mm/s、1.2/s 的速度包络向 -50 mm 收敛
-> 误差 6~15 mm 之间平滑切回位置反馈，并叠加 40 FPS 单帧速度提前反刹
-> 自适应目标角先低通，并限制每帧最多变化 0.45°
-> 终点自适应从当前制动角的 ±2° 范围接管，再学习 -5 cm 局部平衡偏置
-> 距目标 15 mm 内高速接近时，只有单帧位移与融合速度同向才提前反刹
-> 在目标区连续低动 100 ms 后冻结当前实际摆杆角并停止 P/D
-> 冻结角验稳 250 ms，窗口摆幅 <=2 mm 且末端球速 <=4 mm/s 时完成
-> 完成后再次明显滑动会解除冻结，继续自适应保持 -50 mm
```

完成时间 `<=5 s` 标记 `PASS`，否则标记 `LATE`。超过 5 秒不会突然
关闭摆杆，而是继续完成动作并输出警告，便于定位去程或回程过慢。
自然完成后继续保持验稳时锁定的局部平衡角，直到 B21、`STOP` 或切换模式关闭滚球
控制和步进位置跟踪。正程固定角、反向送球和制动阶段关闭 PID 积分，
但摄像头仍持续更新位置与球速。普通模式超过 `150 ms`、
第三问超过 `250 ms` 未更新时，负向制动阶段继续保持已计算的负制动角，
避免小球冲出视野后立即失去制动力；其它动作阶段回到水平，完成态只保留
限幅后的已学习偏置。启动
M2/Q3 时自动开启 `100 ms` 诊断日志。

## 灰度采样和误差

传感器输出约定：

```text
bit0 = 车头最左侧
bit7 = 车头最右侧
黑线 = 1
白底 = 0
```

每次控制更新直接保留原始位图，再按中心轻修正、外侧增强的非线性权重
计算浮点误差：

```c
{-16.0, -8.0, -4.0, -2.0, 2.0, 4.0, 8.0, 16.0}
```

所有黑色探头的权重求和后除以命中数量，直接得到 `line_error`。
误差为负表示黑线偏左，误差为正表示黑线偏右。当前不使用位图多数
表决、误差低通或微分。4、5 号探头单独命中时误差为 `-2/+2`，
只产生小幅回中；向外侧移动后修正逐级增强。

## 连续巡线控制

灰度外环周期为 `10 ms`。灰度误差先转换为目标 yaw 角速度：

```text
target_yaw_rate = clamp(-5 * line_error, -60, +60)
```

BNO085 以 `50 Hz` 输出新 yaw。控制器只在新样本到达时求导，跨越
`+180/-180` 时使用最短角差，再用 `alpha=0.35` 低通得到实测角速度。

```text
turn_rpm = clamp(0.55 * target_yaw_rate
                 + 0.15 * (target_yaw_rate - measured_yaw_rate),
                 -40, +40)
center_rpm = selected_base_rpm - abs(turn_rpm)
left_target  = center_rpm - turn_rpm
right_target = center_rpm + turn_rpm
```

差速增大时中心速度立即下降；普通模式出弯时中心速度每 `10 ms` 最多
恢复 `2 RPM`，M4/M5 最多恢复 `1 RPM`。M4/M5 的内轮最低目标为
`25 RPM`，外轮按转向强度提高并限制在 `95 RPM`；单轮目标每周期最多
增加 `3 RPM`，但减速立即生效。
M4/M5 的误差绝对值超过 `2` 后，只将超出部分放大 `1.5` 倍，
让车辆在到达边缘探头前提前建立角速度。
这样灰度已回中而车身仍有角速度时，
角速度误差会产生反向差速，主动制止继续旋转。

连续 `150 ms` 没有有效 BNO085 角速度时，控制器自动回退到原灰度
`Kp=2.5` 的内轮减速逻辑。普通模式任一路目标不高于 `30 RPM` 时
直接设为 `0 RPM`；M3/M4/M5 最低保持 `25 RPM`。地图不按 B/C/D
编码器位置改变转向速度，也不叠加路段前馈；M3 只在终点判断中读取
A→B 编码器距离。

## M3 第 4 问滚球与停车

M3 起步先保持底盘静止 `200 ms`，其中最后 `180 ms` 将摆杆渐入
`-0.85°` 预置角；随后从 `30 RPM` 通过 `1400 ms` 三次平滑曲线升至
`88 RPM`，预置角在起步后 `600 ms` 平滑退出。到 `4950 count` 后开始预减速，到
`5700 count` 时降至 `35 RPM`。满足 B 点组合条件后进入独立
`STOPPING` 子阶段：捕获速度环当前左右轮占空比、关闭 PI 更新，并在
`900 ms` 内用三次 S 曲线把两路 PWM 衰减到 0。距离减速前馈在前半程
升到 `+0.70°` 后不再回零，最终停车从该角连续接管，并叠加峰值
`+0.45°` 的钟形制动项。PWM 归零后只有
球仍在正侧并继续向正侧滚动才保留接球角；球已越过中心或已经反向时
不再重新施加，以减小钢球穿越中心后的二次过冲。
起步负前馈只有在小球回到 `X>=-2 mm` 后才允许按速度撤销，防止速度尖峰
使补偿提前消失；停车正前馈在 `X=-8~-2 mm` 仍可用于抵消正向惯性，只有
小球已经落到 `X<-8 mm` 才直接禁用。
第四问滚球中心保护从 `2 mm` 偏差开始介入，按 `0.055°/mm` 叠加并限制到
`0.75°`；球向中心运动时按当前速度减弱，达到规划回中速度后退出。Q4
另外用 `35~140 ms` 短窗估速，换向时立即使用新速度方向，并叠加
`0.018°/(mm/s)`、最大 `0.90°` 的专用速度阻尼。第四问行驶
回中速度包络设为 `15 mm/s` 和 `0.50/s`，停车后切换为
`15 mm/s` 和 `0.5/s`。停车后的 `±10 mm` 内关闭额外位置保护；超界且
球速不高于 `6 mm/s` 时按 `0.10°/mm`、最大 `1.0°` 温和回中。包络目标
始终是中心 `0 mm`，目标速度随剩余距离降低，实际速度超过目标时速度项
会反向制动，形成“先加速回拉、后提前减速”的轨迹。
中心保护仍与速度包络叠加，避免大误差区仅靠速度跟踪导致回拉不足。4/5 号中心
探头的误差缩放为 `0.5`，减少直线来回摆动；外侧误差保持原值。右二探头为 `bit6 / 0x40`，
4500 count 后才允许锁存，防止直线摆动误判。最终条件为：

启动时球向车后滑对应 `X<0`，速度 S 曲线同步叠加峰值 `-1.10°` 的角度
前馈；B 点前减速使用 `+0.70°` 的反向前馈，并保持到最终停车接管。
普通巡航时前馈为 0，
不会写入 PID 积分，也不会影响第三、五、六问。

```text
(right_second_seen && distance >= 5700)
||
distance >= 5950
-> STOPPING 900 ms
-> 完成停车
```

第一项表示已经识别到 B 点右弯特征且车轴越过 B 点约 9.8 cm；第二项用于
传感器未触发时按约 1.67 m 兜底。两个距离都是缓停触发点，不是 PWM
立即归零点。

M3 起跑前要求软件零点有效、摄像头帧新鲜且 `abs(X)<=10 mm`。程序保留
赛前设置的 PID、水平 trim 和输出方向，清空旧积分后自动设定 `Set=0 mm`
并开启步进位置跟踪。运行中按原始摄像头位置记录最大绝对误差，`MAP?`
输出 `En/Ready/X/Max/Limit` 和速度阶段 `START/CRUISE/BRAKE/STOPPING`。摄像头持续
失联时停止旧位置反馈，只保留底盘起步/减速前馈，底盘继续循迹；
视觉恢复后自动重新接管；
正常到 B 后 OLED 显示 `M3 B PASS` 和用时，只停底盘并继续保持小球中心。

## M4/M5 第 5、6 问基础循迹

M4 和 M5 共用完整带球循迹配置，并使用独立的写死完成检测：

```text
起跑时清零平均编码器距离和 BNO085 累计实际转角
-> 平均编码器达到 25590 count
-> 同时累计实际转角达到 360°
-> 若 IMU 无新数据、超时或整段近似 0°，则仅按编码器终点停车
-> 不再等待或识别 A 点 3 路黑线
-> 捕获当前 PWM 并用 500 ms S 曲线降到 0
-> M4/M5 切换到停车滚球包络并继续保持目标
-> 记录一圈时间和全过程最大位置误差
```

M4/M5 先保持底盘静止 `200 ms`，再从 `30 RPM` 用 `1400 ms` S 曲线
升到 `85 RPM`。接近中线时
复用 M3 的误差减半逻辑，不再额外低通；转向误差按当前基础速度与
`80 RPM` 的比例缩放，稳态系数约为 `1.063`。出弯恢复仍为
`1 RPM/10 ms`。内轮最低保持 `25 RPM`，单轮目标每 `10 ms` 最多
增加 `3 RPM`，外轮最高为 `95 RPM`，减速仍立即生效。中心误差保持
不变，绝对值超过 `2`
后只放大超出部分，增益为 `1.5`，从中间向外一档便提前转向。外侧
安全限幅、丢线保持和终点判断不变。

在 B/D 附近，`map_curve_hold` 用编码器窗口和右侧探头共同锁定当前半圆：

```text
最外两路，或靠近弯道后右三探头连续 2 次
-> 最低保持 30 deg/s 右转目标
-> BNO085 处理 ±180° 跨界并累计右转角
-> 170~175° 将最低右转目标由 30 降到 10 deg/s
-> 右转达到 175° 且 4/5 中线连续确认 3 次
-> 50 ms 消旋，随后 200 ms 将灰度控制由 0 渐入到 100%
-> 实测角速度降至 ±5 deg/s 后退出，最长过渡 400 ms
-> 退出保持，恢复普通灰度串级
```

若中线漏检，累计达到 `190°` 后释放最低右转约束，避免无限绕圈。
M4/M5 按键起跑时自动开启滚球 PID 和步进位置跟踪。M4 每轮强制
`Set=0 mm`；M5 在 B21 短按时把最新摄像头位置写入
`g_q6_target_position_mm` 并锁定为本轮目标，运行中不允许改变。两种模式都要求起跑时球处于目标 `±10 mm`，使用
`20 mm/s、0.75/s` 的位置-速度包络、短窗速度阻尼、速度耦合位置保护和峰值
`-1.55°` 起步前馈。起步前 `180 ms` 建立 `-1.05°` 预置角，起步后
`600 ms` 退出；起步合成前馈单独允许到 `2.2°`，巡航仍限制为 `1.5°`。
终点缓停叠加峰值 `+0.80°` 制动前馈。短时丢球继续预测；持续 `300 ms` 无有效位置时
只让摆杆回标定水平，底盘继续跑，恢复有效帧后重新接管。

完成 A 点后以 `30 s` 和最大原始位置误差 `10 mm` 分别判定
`LATE/OVER`，两者均满足显示 `PASS`。底盘停止后球控改为
`15 mm/s、0.5/s` 包络继续保持，并在漂出目标 `±10 mm` 且近似静止时
启用温和位置保护。Q5/Q6 默认关闭长 CSV 自动日志，改为
每 `250 ms` 发送精简 `Q5BALL/Q6BALL` 状态，末尾包含编码器距离和累计
实际转动量；需要完整调试时由用户在起跑后
发送 `BALL,LOG,ON`，此时精简状态自动暂停，避免两套日志同时阻塞巡线。
任务完成后精简状态继续发送 `5 s`，用于确认停车后是否继续漂移。
固定安装坡度仍由独立 `level trim` 补偿，不要求软件零点绝对水平。

## 滚球位置控制

摄像头 UART2 提供：

```text
BALL,frame_id,timestamp_ms,x_mm,valid
[BALL] POS:+11.5cm
```

标准帧短暂出现 `valid=0` 时不采用其中的 `x=0`；连续 `40 ms` 没有新帧
也进入相同处理。控制器从最后有效滤波位置按当前球速做衰减外推，最长
`100 ms`、位移最多 `±12 mm`；有效帧恢复后再用原低通平滑接回，持续
丢球才进入原失联保护。

控制链如下：

```text
新摄像头帧
-> 位置低通
-> 使用摄像头 timestamp_ms 计算球速
-> 按可调延迟外推预测位置，预测位移限制 ±20 mm
-> 大误差时根据剩余距离生成先加速后减速的目标速度
-> 目标附近 PID 与远端速度包络平滑混合
-> 始终叠加固定管道水平补偿 trim
-> 持续静止且仍有明显误差时叠加静摩擦脱困补偿
-> 根据位置误差和球速生成动态角度上限
-> 生成目标摆杆角，最终硬限幅 ±4.0°
-> V12 齿轮齿条运动学表分段插值为目标脉冲
-> StepperMotor_Task() 非阻塞追踪目标位置
```

位置环默认 `Kp=0.0075`、`Ki=0.015`、`Kd=0.030`。位置误差不超过
`2 mm` 且速度不超过 `10 mm/s` 时关闭微小 P/D 抖动并保留 I 偏置。
I 只在误差不超过 `20 mm`、速度不超过 `80 mm/s` 时累加，超出时
清零，输出限制为 `±1.5°`。当前 40 FPS 直连链路默认关闭延迟预测，可通过
`BALL,DELAY,ms` 在 `0~200 ms` 调整。误差从 `6~15 mm` 时由普通
PID 逐渐切换到速度包络；普通控制的目标回中速度最高 `60 mm/s`，并按
剩余制动距离提前减速。当前以机械水平姿态重新建立软件零点，因此固定
`trim` 默认 `0.0°`；需要补偿实际安装坡度时再通过命令单独标定，且
不会随目标切换清零。
速度包络本质上是位置外环生成目标速度、速度内环生成摆杆角：远端实际
速度低于目标速度时向目标方向倾斜，接近终点后目标速度下降，若小球仍
过快，速度误差会自然反号并给出反向制动角。
当误差超过 `8 mm`、球速低于 `6 mm/s` 约 `100 ms` 时，按回中
方向叠加与误差相关的 `0.5~1.0°` 静摩擦补偿；若仍持续静止，
则按 `1.8°/s` 增加，正、负方向最高均为 `2.4°`。进入
`±5 mm`、球速达到 `10 mm/s`、相对测速基准已移动 `1.5 mm` 或误差
换向时立即撤销。若中途再次静止则重新触发，不修改 PID 和 trim。
动态角度上限从 `1.5°` 起，随误差和球速增加，计算式为
`1.5 + 0.035*abs(error) + 0.010*abs(speed)`，并限制在 `1.5~4.0°`。
因此远端静止时可以快速起滚，高速接近目标时仍保留制动能力，低速靠近
目标后会自动收角；固定 trim 还会保留 `0.5°` 的可调余量。

第三问正程直接固定 `-4.5°`，确认向右起滚且原始位置达到 `+5 mm` 后提前反坡。
该过程不会修改第四问参数，退出第三问时会恢复启动前保存的 PID。原始位置
达到 `+5 mm` 且即时速度达到 `+5 mm/s` 后，不等待右端停稳，而是暂停 PID 并固定摆杆 `+3.0°`，
利用步进约 `150 ms` 的换坡时间与小球惯性，让实际正端峰值落入
`+40~+60 mm`。返程达到至少 `-100 mm/s` 左移速度且 RawX 回到
`+20 mm` 后，
程序提前下发柔和制动角。模型使用 `|V|+40 mm/s` 作为规划速度，
按固定 `70 mm` 距离计算，并把负制动角限制在 `-1.5~-3.0°`。
这一段不再使用右端峰值、
最短等待时间、提前制动兜底和失败补送，避免视觉量化与旧速度滞后让状态机
重复往返。

制动阶段程序按相邻有效摄像头帧计算即时速度，并以 `75%` 权重与
通用聚合球速融合。能量制动仍用 `v^2=2as` 和实心球
`a≈(5/7)g*theta` 模型，但制动距离固定为 `70 mm`、模型增益为 `3.0`，
不把“到目标还剩多少距离”放在分母，因此经过目标附近或管道坡度奇异点时
不会产生无限大角度。小球向左时先用负角反刹；当 RawX 到 `-35 mm` 且
融合速度降到 `70 mm/s` 以内时，程序提前预置 `+2.2°`，形成一次
`100 ms` 的短上抬波。随后位置外环按
`Vref=clamp(-1.5*(RawX+50), -60, +60)` 规划接近 `-50 mm` 的速度，速度内环
按 `Angle=1.8+clamp(0.040*(V-Vref), -2.4, +2.4)` 调整摆杆角。实际速度比预期
更快时自动反刹，比预期慢时自动补推；捕获段不积分，避免终点积分累积。
低速落入合格区后直接冻结保持角，再按原终点验稳流程处理。
能量制动不会在首次回弹时交出控制权，而是继续吸收回弹动量，
吸收回弹能量。只有即时速度和聚合速度同时满足 `|V|<=12 mm/s` 并持续
`75 ms`，才允许进入终点自适应。若此时 RawX 仍在 `-30 mm` 之前，状态机
恢复固定 `+3.0°` 继续向负端送球；已经越过 `-30 mm` 则直接交给终点
自适应，避免小球停在 `-35 mm` 后因静摩擦无法重新达到制动速度。误差小于
`6 mm` 时，终点自适应阶段角度为
`bias + 0.060*position_error + 0.030*speed`；误差大于 `15 mm` 时改为
`0.030*(speed-target_speed)`，其中目标速度始终指向 `-50 mm`，
绝对值取 `min(35 mm/s, 1.2*abs(position_error))`。`6~15 mm` 之间线性
混合两种输出，因此局部平衡偏置只在接近终点时渐入：远端按受控速度
回收，接近终点再恢复坡度学习和精确位置保持。若位置误差仍大于 `8 mm`、
融合速度不超过 `6 mm/s` 且
单帧位移不超过 `0.5 mm`，则按目标方向直接下发完整 `±4.5°` 破静摩擦
目标角，不再受 `0.45°/帧` 软件斜率拖慢；球恢复运动后立即撤销补偿并
恢复普通 `±3.5°` 限位。`bias` 从当前速度制动角的 `±2.0°` 范围平滑接管，
并以 `0.050` 的积分增益继续修正，只在
`|position_error|<=25 mm` 且 `|speed|<=10 mm/s` 时学习，并限制为
`±2.0°`，总倾角限制为 `±3.5°`。它会针对 -5 cm 处实际坡度和摩擦在线
找到局部平衡角，不再假定整根管道共用固定水平角，也不再切回通用 PID。
单帧滤波位置变化达到 `0.5 mm` 时，按 `40 FPS` 估算当前速度并以 `75%`
权重和聚合速度混合后用于 D；低速时仍使用聚合速度。计算出的目标角再用
`0.5` 一阶低通，并限制每帧最多变化 `0.45°`，避免 1 mm 坐标量化让步进
目标反复大幅换向。进入终点闭环时保留当前制动角的受限部分作为初始局部
坡度估计，不先跳回 `0°`。随后 `5 s` 内保留一次高速越界制动机会：只有越过 `-50 mm` 后
仍以至少 `15 mm/s` 远离，才直接给与速度方向同号的 `±4.5°` 制动角；
接近目标时继续使用速度包络减速，禁止在真实折返点前按旧速度方向反坡。
高速远离期间继续允许 `±4.5°` 动态反刹，重新朝向目标后恢复 `±3.5°`
普通限位。停稳判定使用融合速度，避免聚合速度在反向点
滞后为零而误锁。球进入 `-60~-40 mm`、融合速度 `<=8 mm/s` 且单帧位移
不超过 `1 mm` 后，还需连续保持 `100 ms`、窗口摆幅不超过 `1 mm`；确认后
冻结当时已经有效的实际角度，不再跳到偏置或叠加固定方向推力。冻结后
`250 ms` 内摆幅不超过 `2 mm` 且末端球速不超过 `4 mm/s` 才冻结总时间；
报完成后仍监视位置与速度，若小球因静摩擦释放而重新移动，则解除冻结并
继续运行终点自适应保持，避免成绩输出后从 `-5 cm` 再次滑走。
若单帧移动、窗口摆幅或球速重新超限，则解锁并恢复自适应。
实测周期抖振只会引起机构振动，不能带动小球，因此已经停用；脱困达到
上限仍无运动时保持单向倾角，不再反复改变步进目标。
连续短帧先累计到至少 `75 ms` 再更新球速，窗口内位置变化不超过
`1 mm` 时按静止处理；速度时间窗超过 `250 ms` 时清零旧速度并重建
基准。普通模式有效数据超过 `150 ms`、第三问超过 `250 ms`、第四问超过
`300 ms` 未更新时，目标
脉冲自动回到软件水平零点。`BALL?` 会显示当前 `Timeout`。当前 STEP 频率为
`8000 Hz`，STEP 高电平
约 `10 us`。
简化的 cm 格式没有摄像头时间戳，程序会使用 MSPM0 收帧时间估算 `dt`；
标准格式仍是后续提高速度估计精度的推荐方案。

## 丢线状态保持

运行中八路全白时，M4/M5 保留最后有效灰度误差并继续更新 BNO085
角速度内环，避免弯中冻结旧轮速；其他模式严格保持丢线前左右轮目标。
所有模式都不会因全白自动停机，重新检测到黑线后恢复使用当前帧误差。

起跑时如果八路全白，因为没有可保持的历史状态，程序仍拒绝启动并在
OLED 显示 `NO LINE START`。

## 编码器和速度环

编码器采用 A 相双边沿计数、B 相判方向，车轮实测约 `728 count/圈`。
应用层读取的是已经统一为“车辆前进为正”的累计计数。

速度任务每 `20 ms` 执行；自动 VOFA 遥测默认关闭：

```text
MotorSpeed_Update(elapsed_ms)
-> MotorSpeedLoop_UpdateLeftWheel(elapsed_ms)
-> MotorSpeedLoop_UpdateRightWheel(elapsed_ms)
-> 开启遥测开关时发送 VOFA 速度帧
```

不高于 `30 RPM` 的非零目标使用低速开环映射；高于 `30 RPM` 使用 PI 闭环。
当前左右轮 PI 均为 `Kp=0.1`、`Ki=0.2`。

编码器反馈看门逻辑会监测非零目标下的计数变化。如果目标已持续输出而对应
编码器在规定时间内没有反馈，程序关闭电机，避免反馈断线时 PI 持续加大 PWM。

## 一圈停车

起点 A 是一条横线，多路探头会同时为黑。停车逻辑分三步：

1. 平均编码器超过 `120 count`，且黑色探头不多于 3 路，连续确认 3 次，
   认为已经离开起点横线。
2. 平均编码器达到 `21300 count` 后，才允许终点横线触发停车。
3. M4/M5 还必须确认第二个半圆已经退出，避免弯道宽线误触发。
4. 解锁后至少 3 路探头连续 3 次为黑，认为重新到达 A 点。
5. M1/Q2 让 AT8236 主动刹车 `100 ms` 后恢复全低；M4/M5 平滑停车。

M1 在 `21000 count` 后还会启用终点航向外环：起跑 yaw 是目标航向，
归一化后的航向误差按 `2.0 (deg/s)/deg` 生成最多 `±40 deg/s` 的修正，
与灰度目标角速度相加后交给原 BNO085 角速度内环。若末段短暂全白，
只要 BNO085 数据仍新鲜，就暂时只靠该航向环继续对正；其它路段仍保持
原来的丢线目标。

编码器不单独决定最终停车，只控制终点解锁；真正停车仍由横线传感器确认。

## 实车验收要点

1. 停机手动遮挡最左、最右探头，确认 `LINE?` 分别得到
   `G=00000001 E=-16.00` 和 `G=10000000 E=+16.00`。
2. M1/Q2 使用 `120 RPM`；M3 使用 `30→88 RPM`；M4/M5 静止预置
   `200 ms` 后从 `30 RPM` 平滑升到 `85 RPM`。
3. 手动向左旋转车身，确认 `MAP?` 的实测 yaw 角速度为正且 `F=1`。
4. 用 `MAP?` 核对目标/实测角速度、`C=1` 串级状态和左右轮目标。
5. 验证 M4/M5 全白时继续保持最后转向方向，重新见线后恢复实时误差。
6. 验证 A 点横线停车和单圈用时小于 `20 s`。
