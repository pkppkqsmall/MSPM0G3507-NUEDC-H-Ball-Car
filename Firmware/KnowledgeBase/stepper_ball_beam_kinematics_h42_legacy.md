# [历史参考] H42 四连杆滚球摆杆机构运动学

> 本文件只对应旧 `H42装配.stp` 四连杆方案。当前 V12 装配已经改为
> 步进电机、小齿轮和竖直齿条直驱，本文脉冲表禁止用于当前机构。

## 文档用途

本文件记录 `H42装配.stp` 中步进电机、曲柄、连杆和摆杆的实测几何参数，
用于计算步进电机角度、STEP 脉冲数和摆杆角度之间的关系。

数据于 2026-07-29 使用 OpenCascade 直接解析 STEP 的装配坐标和孔轴圆柱面。
全部长度单位为 `mm`，角度单位为度。

> STEP 文件只保存当前装配几何，没有保存运动副、实体碰撞、间隙和弹性信息。
> 本文结果是理论运动学值，最终软件限位必须经过实机低速验证。

## 四连杆计算

设：

- 摆杆固定轴为 `A`。
- 电机轴心为 `O`。
- 曲柄半径为 `r = OC`。
- 竖连杆长度为 `s = CB`。
- 摆杆长度为 `L = AB`。
- 电机曲柄角为 `theta`。

曲柄销轴坐标：

```text
C.x = O.x + r * cos(theta)
C.z = O.z + r * sin(theta)
```

令 `d = |AC|`，两个圆的交点辅助量为：

```text
a = (L^2 - s^2 + d^2) / (2d)
h = sqrt(L^2 - a^2)
```

以当前 STEP 装配所在的上方交点为准，求出摆杆销轴 `B` 后：

```text
beam_angle = atan2(B.z - A.z, B.x - A.x)
```

因此摆杆角与电机角不是固定比例，不能只用一个常数直接换算。接近机构极限时，
同样的电机角变化会产生不同的摆杆角变化。

## 16 细分脉冲换算

当前软件和 ZDT 驱动器均按 `16` 细分：

```text
每圈脉冲数 = 200 * 16 = 3200 pulse
每个脉冲对应电机角 = 360 / 3200 = 0.1125°
```

电机相对角对应的理论脉冲数：

```text
pulse = motor_relative_angle / 0.1125
```

该换算描述的是 MSPM0 发出的指令位置，不是 ZDT 编码器反馈的绝对位置。

## 水平零点

STEP 当前摆杆角为 `-2.599°`。按照理论模型，从当前姿态向几何正方向转动：

```text
电机相对角：+15.579°
16 细分脉冲：+138.5 pulse
```

即约发送 `139` 个脉冲后，摆杆应到达理论水平位置。实机建议流程：

1. 低速向正方向点动，确认管件右端是否上升。
2. 从 STEP 当前姿态附近发送约 `139` 个脉冲。
3. 用 BNO085 和水平尺确认真正水平位置。
4. 将实测水平位置设置为软件零点。

如果管件右端反而下降，应反转软件方向定义，不能继续按理论正方向运行。

方向后，再决定是否扩大到 `-3° .. +3°`。

## 机械边界与危险区

只考虑杆长、不考虑实体碰撞时：

| 项目 | 相对 STEP 当前姿态 |
| --- | ---: |
| 曲柄理论最小角 | `-76.490°` |
| 曲柄理论最大角 | `+56.677°` |
| 摆杆最高角 | 约 `+3.201°` |
| 达到摆杆最高角时的电机相对角 | 约 `+46.287°` |

关键结论：

1. 这个装配是受限四连杆，电机不能连续旋转很多圈。
2. 正向超过约 `+46.287°` 后，电机继续正转时摆杆会开始反向运动。
3. 接近 `-76.490°` 或 `+56.677°` 时会靠近机构死点，禁止把理论边界当作正常限位。
4. 实体碰撞、螺钉头、连杆厚度和装配误差会让真实范围比理论范围更小。
5. 安装到机构后，不应再调用“整圈正转、整圈反转”的演示动作。

## BNO085 反馈注意事项

摆杆在 X-Z 平面运动，实际旋转轴沿 Y 方向。BNO085 应使用 `roll`、`pitch`
还是 `yaw`，取决于传感器在管件上的安装方向，不能仅凭名称确定。

实机确认方法：

1. 固定 BNO085，保持其他方向不动。
2. 手动抬高和降低管件右端。
3. 观察 `roll`、`pitch`、`yaw` 中哪个角变化最明显。
4. 选择该角作为摆杆反馈，并确认抬高右端时的正负方向。
5. 上电静止时记录零偏，水平标定后再闭合角度环。

如果当前 OLED 只显示 `yaw`，它只能证明 BNO085 正常输出，不能证明 `yaw`
一定就是摆杆控制角。

## 后续软件实现建议

1. 将水平位置定义为步进软件位置 `0`。
2. 给位置指令加入至少 `-133 .. +165 pulse` 的第一阶段软件限位。
3. 使用表格或四连杆反解把摆杆目标角转换成电机位置，不能使用固定比例。
4. 对目标位置加入速度和加速度限制，避免连杆冲击。
5. 使用 BNO085 摆杆角闭环修正理论模型误差。
6. 上电后如果没有限位开关或绝对位置反馈，程序不知道曲柄的真实绝对位置，
   必须先执行人工水平标定或机械回零。
7. ZDT 闭环可降低步进失步风险，但 MSPM0 未读取驱动器反馈时，软件位置仍只是
   已发送脉冲的累计值。

## 当前软件接入状态

`App/MapRun/ball_beam_controller.c` 已使用本页 `-2.5°~+2.5°` 表格进行
分段线性插值，第一阶段控制角进一步限制为 `±2.0°`，因此正常目标约为
`-107~+125 pulse`。`Drivers/StepperMotor/stepper_motor.c` 已支持在
主循环中非阻塞追踪变化的目标脉冲。

该接入不等于机械零点已经验证。上电后仍必须人工调平并发送
`BALL,ZERO`，确认 DIR 对应方向后再发送 `BALL,ON`。当前驱动的 STEP
频率已提高到 `8000 Hz`；本旧机构文档中的低速验证说明不再代表当前构建。
