# 小车参数记录

> 当前运行入口是 `App/MapRun/map_run.c`。本文只记录当前连续巡线地图程序
> 仍在使用的参数，完整操作见 [`../README_MAP_RUN.md`](../README_MAP_RUN.md)。

## 硬件方向

| 项目 | 当前约定 |
| --- | --- |
| 左轮 PWM 正值 | 小车前进方向 |
| 右轮 PWM 正值 | 硬件方向相反，由底层符号统一为小车前进 |
| 速度目标正值 | 小车前进 |
| yaw 正方向 | 串级控制假设左转为正，首次测试必须手动旋转确认 |

右轮方向统一在电机驱动内部完成：

```c
#define RIGHT_WHEEL_DIRECTION_SIGN (-1.0f)
```

应用层始终使用“左右轮正 RPM 都表示小车前进”的语义。

## 当前底盘

当前使用 WHEELTEC R3X 加大版三轮差速底盘。

| 项目 | 当前值 |
| --- | ---: |
| 底板外形 | `320 x 240 x 5 mm` |
| 左右驱动轮中心距 | 模型标注约 `214.2 mm` |
| 驱动轮轴至万向轮轴距 | 模型标注约 `204.7 mm` |
| 轮胎直径 | `65 mm` |

模型尺寸只用于建立初始参数，左右轮中心距和传感器前伸距离应在装车后实测。

## 电机和编码器

| 参数 | 当前值 |
| --- | --- |
| 编码器线数 | `13 PPR` |
| 当前等效计数倍频 | `2` |
| 减速比 | `1:28` |
| 电机轴每圈计数 | `13 * 2 = 26` |
| 车轮输出轴每圈计数 | `26 * 28 = 728`，现场实测约 `728` |
| 测速采样周期 | `20 ms` |

```text
每圈周长约 204.2 mm
每厘米约 35.65 count
```

## 灰度传感器

当前使用感为 8 路灰度模块的串行输出，黑线为 `1`、白底为 `0`。

| 项目 | 当前约定 |
| --- | --- |
| `INPUT1` / bit0 | 车头最左侧，单独命中显示 `00000001` |
| `INPUT8` / bit7 | 车头最右侧，单独命中显示 `10000000` |
| 探头权重 | `{-16.0, -8.0, -4.0, -2.0, 2.0, 4.0, 8.0, 16.0}` |
| 黑线偏左 | 误差为负 |
| 黑线偏右 | 误差为正 |
| 运行中丢线 | 保持最后有效灰度修正和左右轮目标，不自动停机 |

程序保留每次读取的原始位图，直接计算所有黑色探头的平均权重。
不使用位图多数表决或灰度误差低通。中心探头只给小目标角速度，
向外逐级增强；BNO085 失效时才使用 `Kp=2.5` 的灰度 P 回退。

`200 ms` 后从 `30 RPM` 在 `1400 ms` 内升到 `85 RPM`。M3 在中心 4/5 号探头区域把误差与
回退修正减半；M4/M5 复用相同中心整形，不再低通误差，并按当前
基础速度相对 `80 RPM` 的比例缩放转向需求。
运行中全白时，M4/M5 保持最后灰度误差并继续角速度环，其他模式保持
最后左右轮目标；重新找到黑线后继续使用实时灰度误差。
M1/Q2 转弯时外轮固定 `120 RPM`，只降低内轮，不再使用中心速度缓慢
恢复。M4/M5 将内轮最低目标保持在 `25 RPM`，
外轮按转向强度提高并限制在 `90 RPM`，单轮目标增加量限制为每周期
`3 RPM`；减速不延迟。M3 出弯中心速度每周期恢复 `2 RPM`，M4/M5
每周期恢复 `1 RPM`。M4/M5
保持 `85 RPM` 基础速度，但将绝对值超过 `2` 的误差增量放大 `1.5`
倍，让弯道转向更早建立。B/D 附近最外两路可在宽窗口内触发，右侧
第三路在更靠近弯道的位置连续确认 2 次也可提前触发。保持期间 BNO085
累计右转角；`170~175°` 逐步减小最低右转量，随后通过灰度渐入进入直道。

左右轮目标为：

```text
target_yaw_rate = clamp(-5.0 * line_error, -60, +60)
turn_rpm = clamp(0.55 * target_yaw_rate
                 + 0.15 * (target_yaw_rate - measured_yaw_rate),
                 -40, +40)
center_rpm = selected_base_rpm - abs(turn_rpm)
left_target  = center_rpm - turn_rpm
right_target = center_rpm + turn_rpm
```

串级失效时回退到灰度 P：普通模式外轮保持基础速度，M4/M5 外轮按
转向强度提高至最高 `95 RPM`；内轮仍按 P 修正降低。普通模式任一路
目标不高于 `30 RPM` 时
直接设为 `0 RPM`；M3/M4/M5 则最低保持 `25 RPM`，避免边缘触发产生
`0↔85 RPM` 跳变。

编码器不直接生成弯道差速，但 M4/M5 使用宽距离窗口限制右弯保持的
触发路段；M1/M4/M5 还用于测速、反馈故障保护和一圈终点解锁，
M3 额外用于 A→B 停车。

M1 的编码器距离只负责解锁终点识别，真正停车条件仍是再次检测到 A 点横线，
即 `21300 count` 后至少 3 路黑线连续 3 帧。M4/M5 不再使用横线，平均
编码器达到 `25590 count` 且 BNO085 累计实际转动达到 `360°` 后直接缓停；若 IMU 无新数据、已超时或全程转角近似 `0°`，则由该编码器终点直接触发。
M1 在相同距离后将起跑 yaw 作为目标航向，并把航向误差转换成目标角速度
叠加到灰度外环，再由 BNO085 角速度内环和轮速 PI 完成出弯对正。
M1 横线确认后让 AT8236 保持 `IN1=IN2=1` 主动刹车 `100 ms`，随后
恢复四路低电平；M4/M5 不使用该急刹策略，关闭底盘后继续运行滚球
位置跟踪并切换到较慢停车保持包络。

## 第 4 问 A→B 停车参数

| 参数 | 当前值 | 作用 |
| --- | ---: | --- |
| `MAP_RUN_Q4_SENSOR_ARM_COUNTS` | `4500` | 该距离后才允许右二探头锁存 B 点特征 |
| `MAP_RUN_Q4_RIGHT_SECOND_MASK` | `0x40` | 右边第二个探头，即 bit6 |
| `MAP_RUN_Q4_BRAKE_START_COUNTS` | `4950` | B 点前开始平滑减速 |
| `MAP_RUN_Q4_TARGET_STOP_COUNTS` | `5700` | 已锁存右二黑时，越过 B 点约 9.8 cm 后触发缓停 |
| `MAP_RUN_Q4_MAX_STOP_COUNTS` | `5950` | 传感器未锁存时的缓停兜底触发距离 |
| `MAP_RUN_Q4_APPROACH_SPEED_RPM` | `35.0` | 到正常停车距离时的中心速度 |

第四问前馈在底盘速度轨迹存在加速度时叠加到滚球控制角，普通巡航阶段为
`0°`。距离减速前半段升到 `+0.70°` 后保持，直至最终停车连续接管。
达到终点条件后，程序捕获左右轮实际占空比并在 `900 ms` 内按
S 曲线降到 0；同期从 `+0.70°` 连续接管并叠加峰值 `+0.45°` 的钟形项。
停车后只有小球仍位于正侧并继续向正侧滚动时才保留接球角；若已经越过
中心或已经反向，则不重新施加固定正角，避免停车后二次推向负侧。
`BALL?` 和 `MAP?` 的
`FF` 字段可用于确认实际方向和幅值。`MAP?` 的 `Guard/Damp` 字段显示第四问
中心保护输出；球处于 X 正侧时为正，处于 X 负侧时为负。球已经按规划
速度向中心运动时 `Guard` 会降为 0，`Damp` 则始终与小球速度同号以提供阻尼。

`5700/5950 count` 只负责触发最后缓停，完成时间还会增加最多 `0.9 s`，
预计多前进约 `2~3 cm`。纯计时不参与停车，OLED 只显示实测总用时。

## 调参顺序

1. 确认左右电机与编码器方向一致。
2. 停机时用 `LINE?` 确认左右灰度符号没有反。
3. 手动向左旋转车身，使用 `MAP?` 确认实测 yaw 角速度为正。
4. 使用 `MAP?` 核对灰度误差、目标/实测角速度、串级状态和左右轮目标。
5. 左右摆动先调整灰度到角速度增益或角速度 P，不要先改速度 PI。
6. 圆弧半径不对先调整角速度前馈，再考虑统一基础速度。
7. 运行中丢线不会自动停机，实车测试时必须保留人工停机手段。
