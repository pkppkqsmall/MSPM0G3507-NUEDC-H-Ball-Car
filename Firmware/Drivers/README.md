# Drivers

## 目录职责

本目录统一存放底层驱动和硬件相关模块。应用层通过这些接口访问硬件，尽量避免在 `App/` 中直接操作寄存器。

| 目录 | 作用 |
| --- | --- |
| `Button/` | 按键扫描、电机启停状态和目标速度入口。 |
| `motor/` | PWM 输出、编码器测速、速度环和电机方向适配。 |
| `UART/` | 串口/蓝牙收发、命令解析、VOFA/AI 调参数据输出。 |
| `Sensor/` | 感为八路灰度的软件 I2C、在线检测和数据读取。 |
| `BNO085/` | BNO085、I2C HAL、SH-2/SHTP 和姿态角数据。 |
| `StepperMotor/` | STEP/DIR 脉冲、方向、圈数和指令角度统计。 |
| `MPU6050/` | 原 MPU6050 参考源码；当前步进示例不编译该目录。 |
| `OLED_Hardware_I2C/` | OLED I2C 显示驱动。 |
| `MSPM0/` | 时钟、SysTick、基础中断等芯片平台辅助代码。 |

## 移植建议

| 场景 | 优先检查 |
| --- | --- |
| 更换芯片 | `MSPM0/`、SysConfig、启动文件和中断名。 |
| 更换电机驱动 | `motor/` 中的 PWM 通道、方向符号和死区补偿。 |
| 更换蓝牙串口 | `UART/` 和 SysConfig 中的 UART 实例、引脚、波特率。 |
| 更换灰度模块 | `Sensor/` 的 I2C 地址、引脚、上拉电压和黑白电平约定。 |
| 更换 OLED | `OLED_Hardware_I2C/` 的 I2C 配置和显示 API。 |

移植时先保证目标工程能找到每个子目录的头文件，再逐个验证驱动接口是否正常。
