# 感为八路灰度传感器

## 当前引脚

步进工程使用感为模块的单向串行接口，并复用原灰度插座前三路信号：

| 灰度模块 | 工程宏 | 原接口 | MSPM0G3507 引脚 |
| --- | --- | --- | --- |
| CLK | `Sensor_CLK` | INPUT2 | PA15 |
| DAT | `Sensor_DAT` | INPUT3 | PA16 |
| KEY | `Sensor_KEY` | INPUT1 | PA13 |
| 人机按键 | `GPIO_Button_PIN_Button_PIN` | B21 | PB21 |

## 接线与跳线帽

| 灰度模块 | 主控 |
| --- | --- |
| VCC | 稳定 5V |
| GND | 公共 GND |
| CLK | PA15 / 原 INPUT2 |
| DAT | PA16 / 原 INPUT3 |
| KEY | PA13 / 原 INPUT1 |

- 安装灰度模块的**开漏模式**跳线帽，然后断电重新上电。
- 不安装 SCL、SDA 的 5V 上拉跳线帽；串行模式不使用这两个接口。
- DAT 在开漏模式下由 PA16 的内部 3.3V 上拉提供高电平。
- CLK 是 PA15 的 3.3V 推挽输出，官方手册允许这样连接。
- KEY 由 PA13 只拉低或高阻释放。接线前先测量模块 KEY 对 GND 的空闲电压；高于约 3.6V 时必须增加三极管或 MOS 管隔离，不能直接连接 PA13。

## 串行读取

主控连续输出 8 个 CLK：

1. CLK 拉低后读取 DAT。
2. CLK 拉高至少保持 5 us，让模块准备下一位。
3. 8 个时钟在 1 ms 内完成。

实车安装方向已确认：bit0 对应最左侧 1 号探头，bit7 对应最右侧 8 号探头。因此 OLED 按高位到低位显示时，最左侧命中为 `00000001`，最右侧命中为 `10000000`。模块输出为白底 `1`、黑线 `0`，驱动会转换为应用层使用的黑线 `1`、白底 `0`。

串行接口只能读取二值结果，不支持 I2C 的模拟量、PING 和寄存器写入。

## B21 自动模拟校准按键

正常 OLED 页面按下 B21 后，程序会在当前 STEP 高脉冲结束后停止步进输出，并自动把灰度 KEY 拉低约 4.2 秒进入校准：

1. OLED 显示 `Place BLACK` 后，把传感器保持在黑场并按 B21。
2. OLED 显示 `Place WHITE` 后，把传感器保持在白场并按 B21。
3. OLED 显示 `Calibration OK` 后返回正常页面并恢复步进演示。

程序使用非阻塞状态机模拟长按和短按，不会在 GPIO 中断里延时。校准结果由灰度模块自身保存，模块重新上电后仍然有效。

## 软件接口

| 接口 | 作用 |
| --- | --- |
| `Sensor_Init()` | 初始化 CLK、DAT 和校准 KEY。 |
| `Sensor_Read_Grayscale()` | 串行读取 8 路数字量并转换为 `1=黑线、0=白底`。 |
| `Sensor_SetCalibrationKeyPressed()` | 只拉低或释放灰度 KEY。 |
| `Sensor_IsReady()` | 查询串行 GPIO 是否完成初始化。 |
| `Sensor_Read_Analog()` | 串行模式不支持，固定返回失败。 |
| `Sensor_Write_Calibration()` | 串行模式不支持，改用 B21 模拟模块按键校准。 |
